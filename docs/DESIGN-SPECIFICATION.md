## 🚀 使用建议

### 对于新功能开发
1. **复用现有配色** - 使用 CSS 变量
2. **遵循间距系统** - 使用 space-* 变量
3. **保持组件一致性** - 参考组件规范
4. **注意响应式** - 考虑移动端体验

### 对于 UI 修改
1. **优先使用 CSS 变量** - 便于全局调整
2. **保持视觉一致性** - 遵循现有设计语言
3. **测试多端显示** - PC 和移动端都要测试

## 📱 移动端优化方案（v2.x → v3.0）

> 当前移动端评分：6.2/10 → 目标：8+/10

### 已知问题 & 修复

| 问题 | 现状 | 修复方案 |
|------|------|----------|
| 日期按钮太小 | < 44px 触摸目标 | 最小高度 44px，内边距 10px 16px |
| 日历视图拥挤 | 日期格过小 | 切换为列表式日期选择 |
| 搜索框被键盘遮挡 | 输入时视口不调整 | `scrollIntoView` + `visualViewport` API |
| 弹窗关闭按钮太小 | 约 24px | 增大至 44px × 44px |
| Tab 横向滚动 | 无视觉提示 | 添加渐隐遮罩提示可滚动 |
| 卡片点击区域小 | 仅文字可点 | 整张卡片可点击 |

### 移动端触摸目标规范

```css
/* 所有可交互元素最小触摸区域 */
min-height: 44px;
min-width: 44px;

/* 搜索框防 iOS 缩放 */
.search-input { font-size: 16px; }
```

## 🎯 动效规范

| 场景 | 动效 | 时长 |
|------|------|------|
| 卡片入场 | `translateY(20px)` → `0` + `opacity` | 300ms ease-out |
