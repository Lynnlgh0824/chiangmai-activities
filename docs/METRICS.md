## 2. 用户行为指标

### 页面级

| 指标 | 定义 | 采集方式 |
|------|------|----------|
| PV (页面浏览) | 每次页面加载 | GA4 / Vercel Analytics |
| UV (独立访客) | 去重用户数 | GA4 |
| 页面停留时长 | 从进入到离开的时间 | GA4 |
| 跳出率 | 只看一页就离开的比例 | GA4 |
| 首屏加载时间 (FCP) | 首次内容绘制 | Vercel Speed Insights |
| 最大内容绘制 (LCP) | 最大元素渲染完成 | Vercel Speed Insights |

### 搜索相关

| 指标 | 定义 | 重要性 |
|------|------|--------|
| 搜索使用率 | 使用搜索功能的用户占比 | 🔴 高 |
| 搜索关键词 Top 10 | 最热门搜索词 | 🔴 高 |
| 搜索无结果率 | 搜索但无匹配结果的比例 | 🟡 中 |
| 搜索 → 点击转化率 | 搜索后点击活动的比例 | 🔴 高 |

### 筛选相关

| 指标 | 定义 | 重要性 |
|------|------|--------|
| 筛选使用率 | 使用筛选功能的用户占比 | 🟡 中 |
| 热门筛选组合 | 最常用的筛选条件组合 | 🟡 中 |
| 价格筛选偏好 | 各价格区间的选择分布 | 🟡 中 |

## 6. 数据采集方案

### 推荐工具

| 工具 | 用途 | 成本 |

| Google Analytics 4 | 用户行为分析 | 免费 |

### 埋点优先级

| 优先级 | 事件 | 说明 |
|--------|------|------|
| P0 | page_view | 页面浏览 |
| P0 | search | 搜索（记录关键词） |
| P0 | activity_click | 点击活动卡片 |
| P1 | filter_use | 使用筛选 |
| P1 | activity_detail_view | 查看活动详情 |
| P2 | contact_click | 点击联系方式 |
| P2 | share | 分享活动 |
