# 每日工作日志目录

此目录用于记录每日工作内容，**不会提交到Git仓库**。

## 使用方式

### 创建日志文件

```bash
# 格式：YYYY-MM-DD.md
touch daily-logs/$(date +%Y-%m-%d).md
```

### 日志模板

```markdown
# 工作日志 - YYYY-MM-DD

## 今日完成
- [ ] 任务1
- [ ] 任务2

## 遇到的问题
- 问题描述
- 解决方案

## 明日计划
- [ ] 任务1
- [ ] 任务2

## 备注
- 其他需要记录的内容
```

## 公开 vs 私有

- **私有日志** (此目录): 内部工作记录、敏感信息
- **公开日志** (CHANGELOG.md): 版本更新、功能发布
