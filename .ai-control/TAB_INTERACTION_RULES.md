## 当前实现 (V1.0)

### PC端 (> 768px)
```
┌────────────────────────────────────────────┐
│ 兴趣班 | 市集 | 音乐 | 灵活 | 活动网站 | 攻略 │
└────────────────────────────────────────────┘
```
- 显示全部 6 个 Tab
- 无"更多"按钮

### 移动端 (≤ 768px)
```
┌───────────────────────────────┐
│ 兴趣班 | 市集 | 音乐 | 灵活 | 更多 ▾ │
└───────────────────────────────┘
         ↓ 点击更多
┌─────────────────────┐
│  🏪 活动网站         │
│  📖 攻略信息         │
└─────────────────────┘
```
- 显示前 4 个 Tab + "更多"按钮
- 点击"更多"弹出下拉菜单
- 固定断点：768px

**问题**：
- ❌ 断点固定，不够灵活
- ❌ 平板设备（768-1024px）可能显示不全
- ❌ 大屏手机可能显示更多Tab

## 新方案 (V2.0): 自适应Tab导航

### 设计思路

**核心原则**：根据可用宽度动态计算显示的Tab数量

### 规则

1. **计算可用宽度**
   ```javascript
   availableWidth = windowWidth - 搜索栏宽度 - padding
   ```

2. **计算Tab数量**
   ```javascript
   // 每个Tab平均宽度（包含margin）
   avgTabWidth = 100px;

   // 可容纳的Tab数量
   maxTabs = Math.floor(availableWidth / avgTabWidth);

   // 如果能显示全部6个Tab，不显示"更多"
   // 否则显示 (maxTabs - 1) 个Tab + "更多"按钮
   ```

3. **响应式断点建议**

   | 屏幕宽度 | 显示Tab数 | "更多"按钮 | 菜单项数 |
   |---------|----------|-----------|---------|
   | ≥ 1024px (大屏) | 6 | ❌ 无 | 0 |
   | 768-1023px (平板) | 5 | ✅ 有 | 1 |
   | 600-767px (大手机) | 4 | ✅ 有 | 2 |
   | 400-599px (手机) | 3 | ✅ 有 | 3 |
   | < 400px (小手机) | 2 | ✅ 有 | 4 |

## 交互规则

### 桌面端（全部显示）

```
┌────────────────────────────────────────────────┐
│ 兴趣班 | 市集 | 音乐 | 灵活 | 活动网站 | 攻略信息 │
└────────────────────────────────────────────────┘
```

**交互**：
- 点击 Tab → 切换到对应内容
- 选中状态 → 深蓝色背景 + 白色文字
- 悬停效果 → 轻微放大 + 阴影

---

### 平板/移动端（部分显示 + 更多）

```
┌──────────────────────────────────────┐
│ 兴趣班 | 市集 | 音乐 | 更多 ▾        │
└──────────────────────────────────────┘
         ↓ 点击"更多"
┌────────────────────────┐
│   灵活时间活动  ✓      │ ← 当前选中
│   🏪 活动网站           │
│   📖 攻略信息           │
└────────────────────────┘
```

**交互**：
1. **点击"更多"**
   - 显示下拉菜单
   - 位置：固定在屏幕右下角（移动端）
   - 动画：从底部滑入

2. **下拉菜单内容**
   - 显示未展示的Tab项
   - 标记当前选中的Tab（✓）
   - 带图标和文字

3. **点击菜单项**
   - 切换到对应Tab
   - 自动关闭菜单
   - 更新Tab导航（将选中的Tab移入可见区域）

4. **点击菜单外**
   - 关闭下拉菜单

## 视觉规范

### "更多"按钮

**样式**：
- 图标：▾ (向下箭头)
- 文字："更多"
- 选中态：箭头旋转180°向上

**尺寸**：
- 高度：与普通Tab一致（50px）
- 内边距：10px 16px

**颜色**：
- 默认：白色背景 + 灰色文字
- 激活：深蓝色背景 + 白色文字

### 下拉菜单

**位置**：
- 桌面端：按钮正下方
- 移动端：固定在右下角（距离底部80px）

**样式**：
- 背景：白色
- 圆角：8px
- 阴影：`0 4px 16px rgba(0, 0, 0, 0.15)`
- 最大高度：`300px`（超出滚动）
- 动画：`translateY(100%) → translateY(0)` 0.3s

**菜单项**：
- 高度：`48px`
- 内边距：`12px 16px`
- 分隔线：1px solid #eee
- 悬停：浅灰背景

**选中标记**：
- 位置：右侧
- 样式：✓ 绿色对勾
- 或使用蓝色高亮背景

## 实现方案

### 方案A: 纯CSS + Media Queries（当前方案）

**优点**：简单、性能好
**缺点**：断点固定、不够灵活

```css
@media (max-width: 768px) {
    .desktop-only { display: none; }
    .mobile-only { display: block; }
}
```

---

### 方案B: JavaScript动态计算（推荐）

**优点**：自适应、灵活
**缺点**：需要JS计算

```javascript
function updateTabLayout() {
    const containerWidth = tabsNav.offsetWidth;
    const tabCount = allTabs.length;
    const avgTabWidth = 100; // 平均每个Tab的宽度

    const maxVisibleTabs = Math.floor(containerWidth / avgTabWidth);

    if (maxVisibleTabs >= tabCount) {
        // 显示全部Tab，隐藏"更多"
        hideMoreButton();
        showAllTabs();
    } else {
        // 显示部分Tab + "更多"
        showVisibleTabs(maxVisibleTabs - 1);
        showMoreButton();
        updateDropdownItems(maxVisibleTabs - 1);
    }
}

// 监听窗口大小变化
window.addEventListener('resize', debounce(updateTabLayout, 200));
```

---

### 方案C: CSS Flexbox + overflow（最佳）

**优点**：自动适应、无需JS
**缺点**：需要配合"更多"按钮

```css
.tabs-nav {
    display: flex;
    overflow: hidden;
}

.tabs-container {
    flex: 1;
    display: flex;
    overflow: hidden;
}

.tab-item {
    flex-shrink: 0;
}

.tab-more {
    flex-shrink: 0;
}
```

配合JS计算哪些Tab被隐藏，放入下拉菜单。
