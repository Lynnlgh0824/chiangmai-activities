# 清迈活动平台 - AI自动验收标准

**版本**: V1.0
**最后更新**: 2026-02-26

---

## 目标

确保首屏活动展示正确、无错误、符合产品设计。

---

## 一、首屏活动展示验收

**页面**: `/` 或 `/home`

### 必须满足

#### [结构]

✓ 必须存在活动列表容器

**示例结构**:

```html
<div class="activity-list">
  <div class="activity-card">...</div>
</div>
```

#### [数量]

✓ 至少展示 3 个活动

#### [活动卡片必须包含]

✓ 封面图片
✓ 活动名称
✓ 活动时间
✓ 活动地点

#### [点击行为]

点击活动卡片必须：

✓ 跳转至：`/activity/{id}`

---

## 二、页面加载验收

### 必须满足

✓ 页面加载成功
✓ 无白屏
✓ 无报错

**浏览器 Console 不能包含**:

- `error`
- `exception`
- `failed`

---

## 三、接口验收

**接口**: `GET /api/activities`

### 必须满足

✓ 返回 HTTP 200

### 返回结构

```json
{
  "data": [
    {
      "id": "string",
      "title": "string",
      "image": "string",
      "time": "string",
      "location": "string"
    }
  ]
}
```

---

## 四、视觉基本验收

### 活动卡片必须

✓ 图片可见
✓ 文本不为空

### 禁止

- `undefined`
- `null`
- 空白卡片

---

## 五、通过标准

**满足以上所有条件**: **PASS**

**否则**: **FAIL**

---

## 六、今天高亮验收（P0关键）

### 必须满足

✓ 页面默认选中"今天"

✓ 今天具有明显视觉高亮（至少满足2条）：
- 实心背景
- 高对比颜色
- 显示"今天"标签
- 强对比边框（≥3px）

✓ 用户可在0.3秒内识别今天

---

## 七、首屏密度验收（P0关键）

### 必须满足

✓ 首屏必须显示 **≥ 4 个活动卡片**

---

## 八、交互验收

### 必须满足

✓ 点击日期 → 活动列表变化
✓ 点击Tab → 活动列表变化
✓ 点击活动卡片 → 跳转或反馈

---

## 九、验收输出

生成报告：

`.ai-control/ACCEPTANCE_REPORT.md`

**包含**:

- 测试结果（PASS/FAIL）
- 每项测试详情
- 失败原因（如有）
- 优化建议
