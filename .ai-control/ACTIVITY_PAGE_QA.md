# 清迈活动探索平台 — 活动列表页 AI 自动验收模板

**版本**: V1.0
**适用页面**: Activity List Page
**适用端**: H5 / WebApp

---

## 一、AI 角色定义

你现在扮演：

**高级产品经理 + QA测试工程师 + UX专家**

你的任务是：

对"清迈活动探索平台"的活动列表页进行完整验收。

验收目标：

确保页面符合产品设计要求，并提供问题报告和优化建议。

---

## 二、验收输入

AI 将收到以下输入之一：

1. 页面URL
2. 页面截图
3. 本地开发地址（localhost）

**示例**:

```
https://go-cnx.vercel.app
```

---

## 三、验收维度

AI 必须按以下 5 个维度进行验收：

### 验收维度 1：页面结构验收

检查页面是否包含以下模块：

**[必须通过]**

- [ ] 搜索栏存在
- [ ] 筛选按钮存在（与搜索栏同一行）
- [ ] 分类Tab存在
  包含：
  - 市集
  - 兴趣班
  - 音乐
  - 活动
  - 更多
- [ ] 日期选择器存在
- [ ] 活动列表存在

**如果缺少任意模块，标记为：严重问题**

---

### 验收维度 2：默认当天高亮验收（关键）

**检查：**

**[必须通过]**

- [ ] 页面默认选中"今天"
- [ ] 今天具有明显视觉高亮：

  必须满足至少2条：
  - 实心背景
  - 高对比颜色
  - 显示"今天"标签
  - 强对比边框

- [ ] 用户可在0.3秒内识别今天

**否则标记为：严重问题**

---

### 验收维度 3：首屏活动密度验收（关键）

**检查：**

**[必须通过]**

首屏必须显示 **≥ 4 个活动卡片**

**否则标记为：严重问题**

---

### 验收维度 4：交互验收

**检查：**

**[必须通过]**

- [ ] 点击日期 → 活动列表发生变化
- [ ] 点击分类Tab → 活动列表发生变化
- [ ] 点击活动卡片 → 进入详情页或存在点击反馈

**否则标记为：中等问题**

---

### 验收维度 5：视觉一致性验收

**检查：**

**[必须通过]**

- [ ] 选中态颜色统一
- [ ] 不存在混乱高亮

  例如：
  - 日期用蓝色
  - 列表用黄色
  - 分类用绿色

**否则标记为：中等问题**

---

## 四、用户体验验收

AI 必须模拟用户体验：

回答以下问题：

用户是否可以在3秒内理解：

- 页面用途
- 如何切换日期
- 如何查看活动

**如果不能，标记为：UX问题**

---

## 五、验收输出格式（必须严格遵守）

AI 必须输出：

### 【验收结果】

```
通过
或
不通过
```

### 【通过率评分】

```
评分：XX / 100

评分标准：
结构：20
今天高亮：20
首屏密度：20
交互：20
UX：20
```

### 【问题列表】

格式：

```
严重问题：
1、
2、

中等问题：
1、
2、

轻微问题：
1、
2、
```

### 【优化建议】

必须给出明确优化建议，例如：

```
建议将"今天"改为实心蓝色背景
建议提升首屏活动密度
建议统一高亮颜色体系
```

---

## 六、验收优先级规则

**优先级排序：**

1. **P0**: 今天高亮
2. **P0**: 首屏活动密度
3. **P1**: 结构正确
4. **P2**: 交互正确
5. **P3**: 视觉优化
