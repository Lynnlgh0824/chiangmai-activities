# 测试思维方法论

## 核心理念

测试不仅是发现错误，更是验证功能是否满足用户需求。

## 测试金字塔

```
        /\
       /E2E\        <- 少量端到端测试
      /------\
     /集成测试 \     <- 中等数量集成测试
    /----------\
   / 单元测试   \    <- 大量单元测试
  /------------\
```

## 测试原则

1. **自动化优先** - 自动化测试节省时间
2. **快速反馈** - 单元测试应毫秒级完成
3. **独立性** - 每个测试用例应独立运行
4. **可重复性** - 测试结果应稳定可重复
5. **全面覆盖** - 覆盖正常和异常场景

## 测试策略

### 静态测试
- 代码审查
- ESLint 检查
- 类型检查

### 动态测试
- 单元测试
- 集成测试
- E2E 测试

## 调试方法

1. **隔离问题** - 缩小问题范围
2. **假设验证** - 形成假设，逐一验证
3. **二分查找** - 快速定位问题所在
4. **日志分析** - 利用日志追踪问题
