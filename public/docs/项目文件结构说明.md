# 项目文件结构说明

## 目录结构

```
Chiangmai/
├── public/                 # 前端静态文件
│   ├── index.html         # 主页面
│   ├── admin.html         # 管理后台
│   ├── diagnose.html      # 诊断页面
│   ├── css/               # 样式文件
│   ├── js/                # JavaScript 文件
│   ├── data/              # JSON 数据
│   ├── tests/             # 测试页面
│   └── docs/              # 文档
├── server.cjs              # Express 服务器
├── package.json            # 依赖配置
├── src/                    # React 源码
├── scripts/                # 自动化脚本
├── tests/                  # 测试脚本
└── docs/                   # 项目文档
```

## 核心文件说明

### 服务器
- `server.cjs` - Express.js 主服务器，处理 API 请求

### 前端
- `public/index.html` - 主页面入口
- `public/admin.html` - 管理后台
- `public/css/style.css` - 全局样式

### 数据
- `public/data/items.json` - 活动数据文件

### API 路由
| 路由 | 说明 |
|------|------|
| `/api/activities` | 活动数据接口 |
| `/api/version` | 数据版本信息 |
| `/app/version` | 应用版本信息 |
