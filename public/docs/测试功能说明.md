# 测试功能说明

## 测试页面清单

### 基础测试页面

| 页面 | 路径 | 功能 |
|------|------|------|
| 简单测试 | `/simple-test.html` | 基础功能验证 |
| JS加载测试 | `/test-js.html` | JavaScript 加载验证 |
| API连接测试 | `/test-api.html` | API 接口测试 |

### 综合测试面板

| 页面 | 路径 | 功能 |
|------|------|------|
| 综合测试面板 | `/test-dashboard.html` | 所有测试汇总 |
| 增强测试仪表板 | `/tests/test-dashboard-enhanced.html` | 高级测试功能 |

## 运行测试

### 本地测试
```bash
# 启动服务器
npm run start

# 访问测试页面
open http://localhost:4000/test-dashboard.html
```

### 自动测试
```bash
# 运行所有测试
npm test

# E2E 测试
npm run test:e2e
```

## 测试结果

测试结果会显示在页面上，包括：
- ✅ 通过的测试
- ❌ 失败的测试
- ⚠️ 警告信息
